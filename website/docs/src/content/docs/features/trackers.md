title: Trackers
description: Tap-to-log items like a medicine dose — every tap is kept, and each shows when it last happened.

A tracker is a **tap-to-log item**: Tylenol, a vitamin, the dog's heartworm pill. Each tap
records the moment, and the tracker always shows when it last happened — so nobody has to ask
"did anyone give her something already?" ⏱️

Trackers is a module that is **ON by default**. Turn it off in **Settings →
[Modules](/administration/modules/)** and the card, the tab and the routes go away; nothing is
deleted.

## Create a tracker

Adults and admins can add trackers. Open **Tasks → Trackers** (the Tasks page shows if **Chores** or **Trackers** is on, so it is there even with Chores off) and choose **Add tracker**:

- **Title** and **Emoji** — for example *Tylenol* and 💊.
- **Ask who it was for** — see below.

Use **Edit** to change any of these later. **Archive** removes a tracker from Today without losing
its history; **Unarchive** brings it back. Kids can't add, edit or archive trackers.

## Log it

On [Today](/features/today/), each tracker is a tile reading **Last time: 11/23 2:15 PM**
(in the household timezone), or **Not logged yet** if it never has been. One tap logs it.
An **Undo** toast stays up for a few seconds in case you tapped the wrong tile.

The card hides itself when there are no trackers, and you can hide it yourself in Today's
Customize mode. Anyone, kids included, can log.

## Ask who

Turn on **Ask who it was for** and a tap opens a member picker first. The entry is saved with
that person, and the tile shows their name after the time, such as **Last time: 11/23 2:15 PM · Maya**.
Use it when the same item is for different people.

## Fix a mistake

Under **Tasks → Trackers**, choose **History** on a tracker. You can filter by person
(**Everyone** by default) and use **Load more** for older entries. Each entry has:

- **Edit** — fix the time if you logged it late.
- **Delete** — remove an entry that shouldn't be there.

Anyone in the household can edit or delete entries.

## What it doesn't do

Trackers record what happened. There are **no dose limits or "too soon" warnings**, no
reminders and no charts.
